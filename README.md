# Readet

## Prerequisites

- Node.js current LTS
- npm
- Expo Go on a physical device, or an Android/iOS emulator

## Getting Started

From a fresh checkout, run:

```sh
npm install
npm run typecheck
npm run lint
npm test
npm start
```

After `npm start`, follow the Expo CLI instructions to open the app in Expo Go or an emulator.

The expected visible result is `Hello Egor!!!!!`.
