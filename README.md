# Readet Test

An Expo-managed React Native app for iOS and Android.

## Prerequisites

- Node.js 20.19 or later (supported by Expo SDK 54)
- For iOS: macOS with Xcode and an iOS Simulator, or an iPhone with Expo Go
- For Android: Android Studio with an Android emulator, or an Android device with Expo Go

## Install

```sh
npm install
```

## Run locally

Start the Expo development server:

```sh
npm start
```

Then open the app in Expo Go on a physical device, or select an available simulator/emulator.

Launch a configured platform target directly:

```sh
npm run ios
npm run android
```
